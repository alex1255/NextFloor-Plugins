# Security policy

Plugins run in the browser with the same rights as NextFloor, which is why every plugin file in this store is pinned to a commit and a sha256 and reviewed before it is listed.

Found a problem in a listed plugin, in the store or in the validation script? Please do **not** open a public issue. Use [private reporting](https://github.com/therealMRBK/NextFloor-Plugins/security/advisories/new). A confirmed problem leads to the plugin being delisted or fixed, and you get an answer within a few days.

Problems in NextFloor itself: see its [security policy](https://github.com/therealMRBK/NextFloor/blob/main/SECURITY.md).
